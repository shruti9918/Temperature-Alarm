# 🌡️ Temperature Alarm

## 📌 Project Overview

The Temperature Alarm is a simple hardware-based electronic circuit designed to detect a rise in temperature and provide an alarm indication using a buzzer and LED.

The circuit uses a thermistor as the temperature sensing element and a transistor for switching the alarm circuit.

## 🎯 Objective

To design and implement a low-cost temperature alarm circuit using basic electronic components.

## 🔧 Components Used

- 9V Battery
- Thermistor (TH 103)
- BC548 Transistor
- Buzzer
- Red LED
- Yellow LED
- 10 kΩ Resistor
- 1 kΩ Resistor
- 1 kΩ Potentiometer
- Breadboard
- Connecting Wires

## ⚙️ Working Principle

The thermistor senses changes in temperature.

When the temperature reaches the preset threshold, the voltage applied to the transistor changes. The transistor switches the alarm circuit, causing the buzzer and LED to indicate the temperature condition.

The potentiometer is used to adjust the triggering level.
